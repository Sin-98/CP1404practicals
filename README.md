## Lessons Learned About Clean Code

Throughout this subject, I have learned and applied many principles of clean coding. The three key lessons are:

- **Meaningful Naming**: Choose descriptive and consistent variable, function, and class names that clearly convey their purpose.
- **Separation of Concerns**: Write small, single-purpose functions and separate responsibilities across modules or classes to keep code easier to test, maintain, and reuse.
- **Avoiding Repetition (DRY Principle)**: Reuse code instead of duplicating logic; use helper functions or loops when necessary to reduce redundancy and improve maintainability.
